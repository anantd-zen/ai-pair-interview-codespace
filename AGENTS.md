# AI pairing-interview template context

This repository provides reusable interview infrastructure. The active,
candidate-facing exercise lives under `challenge/`.

- Read `challenge/README.md` and `challenge/AGENTS.md` before working on the active challenge.
- Treat `examples/` as authoring references, not as active requirements.
- Do not assume that a challenge has tests or a single predetermined solution.
- Ask clarifying questions when the desired outcome is ambiguous.
- Prefer small, readable steps and verify claims with relevant tools.
- Report uncertainty and failures honestly.
- Do not inspect Git history for prior solutions.
