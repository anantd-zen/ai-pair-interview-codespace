# Active interview challenge

Replace this file with the candidate-facing prompt for your interview.

The active challenge belongs under this directory. Keep it self-contained and
include only material that the candidate is allowed to inspect through the
shared terminal.

Suggested contents:

- the problem context and desired outcome;
- useful commands and entry points;
- constraints that matter to the role;
- sample inputs or data;
- what the candidate may change;
- explicit permission to use Pi and other approved tools.

Tests are optional. This template is intended to support exploratory pairing,
debugging, data analysis, design spikes, and small implementations—not only
pass/fail coding exercises.

See the root README and `docs/` for Python and SQL authoring patterns. Finished
examples live under `examples/` and are not active interview content.
